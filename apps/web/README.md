# PlayPal Web

Vite + React frontend for PlayPal. See the [root README](../../README.md) for setup and scripts.

## Structure

```
apps/web/
├── src/
│   ├── components/     # Pages and UI (HomePage, TeamsList, etc.)
│   ├── config/         # Firebase and maps configuration
│   ├── App.jsx         # Router and app shell
│   └── main.jsx        # Entry point
├── index.html
└── vite.config.js
```

## Local development

From the repo root:

```bash
npm run dev:web
```

Open [http://localhost:5173](http://localhost:5173).
